    clang-format -i main.cpp

---
conanfile — конфигурационный файл для Conan (менеджера пакетов для C и C++).
    В моем случае он помогает с автоматизацией зависимостей. То есть больше не нужно вручную скачивать исходники
        библиотек, компилировать их и прописывать пути к заголовочным файлам.
    Я с его помощью подключаю библиотеки внешних зависимостей к проекту.
---
Doxygen - программа для автоматической генерации документации из исходного кода программ.
    Читает комментарии в коде и создает справочную документацию в разных форматах.

Перед сборкой единожды нужно было установить Conan и создать профиль:
    sudo apt install pipx
    pipx install conan
    conan profile detect
Сборка:
    cd /home/matvey/CLionProjects/NSU_labs_CPP_7-semester/lab1
    conan install . --build=missing
        // читает conanfile.txt и создает файлы в build/Release/generators/ для сборки в преокте этих зависимостей
    cmake --preset conan-release
    cmake --build --preset conan-release
        или cmake --build build/Release
        или cd build/Release && cmake --build .
Установка:
    cmake --install build/Release --prefix install
Запуск тестов (после сборки):
    ctest --preset conan-release -V
        или ctest --test-dir build/Release --output-on-failure
        ПОСЛЕ запуска тестов проверить появление build/Release/test_results.xml
Запуск экзешника compressor:
    ./build/Release/compressor/compressor zlib test_string

ТЗ: Уметь генерировать документацию библиотеки инструментом Doxygen

    cmake --preset conan-release
    cmake --build --preset conan-release --target docs
        // Ранее цели собирались дефолтные: libcompressor, compressor, libcompressortest, а теперь ставится только 1: docs.
        // см. /home/matvey/CLionProjects/NSU_labs_CPP_7-semester/lab1/build/Release/docs/html/index.html

В репозитории должен быть подготовленный pipeline GitHub Actions, который прогоняет этапы сборки проекта.
    Папка workflow должна лежать в корне репозитория: NSU_labs_CPP_7-semester/.github/workflows/lab1.yml, а не в lab1/. Внутри шаги с working-directory: lab1:
      1. checkout;
      2. установка Conan;
      3. conan profile detect;
      4. conan install;
      5. cmake --preset;
      6. cmake --build;
      7. ctest.
